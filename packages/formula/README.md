# @opensheetjs/formula

Part of [OpenSheet](https://github.com/openHacking/opensheet), an embeddable TypeScript spreadsheet.

Version 0.1.0 is a development preview. This package provides ESM and TypeScript declarations and is not published to npm yet. The main browser entry is `opensheet`; scoped packages use `@opensheetjs/*`.

See the [API guide](../../docs/api.md) and [implementation status](../../docs/implementation-status.md) for supported behavior. Local setup, builds and tests are documented in [Contributing](../../CONTRIBUTING.md).
