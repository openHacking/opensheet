# Code of Conduct

Treat contributors and users with respect. We welcome people of all backgrounds and experience levels.

Use constructive feedback, assume good intent and focus criticism on the work. Harassment, discrimination, threats, doxxing and unwanted sexual attention are unacceptable. Do not share private information without permission.

Maintainers may remove inappropriate content or restrict participation. To report a concern, contact a maintainer privately through an available GitHub channel; if none is available, request a private channel without exposing personal details in a public issue.

This policy applies to project issues, pull requests, discussions and other project spaces.
