## Documentation review checklist (DOC-01)

Before release, review README, `docs/api.md`, `docs/implementation-status.md`, all package READMEs and `llms.txt` against this inventory:

The initial cross-document review and registry observation are recorded in [documentation audit](documentation-audit.md). Repeat the review when contracts or publication state change.

`tests/documentation-consistency.test.ts` checks the current formula registry count in the inventory and semantics page, the unversioned directory-head exception on the three current storage pages, and relative inline and same-line reference-definition file targets in the root README, roadmap, TODO, `docs/` Markdown and package READMEs. The link check skips fenced code, same-line inline code, anchors and external URLs; it does not resolve reference usages or verify anchors, and is not a complete Markdown parser. These targeted checks do not establish consistency of the complete documentation set or verify external sites.

- Workbook reads/writes are asynchronous; lightweight metadata and pure file utilities are synchronous.
- A Node import smoke pass does not imply a Node storage engine. Injection must provide the worker/storage runtime and revision coordination.
- Browser requirements include module Workers, IndexedDB, Web Locks and BroadcastChannel. Presence checks do not establish permission, quota or durability under origin eviction.
- npm publication state is distinct from local build state; verify registry artifacts for a release, rather than infer publication from this workspace.
- Never substitute cache reservations for total memory, a hot-cell benchmark for dispersed edits, or historical results for current-commit acceptance.
- Formula count comes from `supportedFunctions`; examples must use only supported modes.
- Distinguish unsupported pre-0.1.1 layouts from the accepted current-layout unversioned directory head; do not imply a general migration or downgrade guarantee.
- Formula-result sorting uses pre-sort calculated keys; verify its implementation and limitations against `docs/formula-sort-design.md` rather than historical research snapshots.
- Label test and benchmark results with their date and source/build fingerprint; do not call a historical full-suite run current after subsequent code changes.
- SheetJS self-roundtrips are regression checks, not independent Excel fidelity evidence.
- Demo charts are host application components; single-writer tabs are not collaboration.
- Internal validation, conditional-formatting and named-range models are not public, persistent features; XLSX rule-loss reports do not imply rule import.
- Manual input/accessibility, independent pilots and release sign-off retain explicit unverified states until records exist.
